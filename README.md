About

GravityContainer is an experimental project inspired by the visual language of modern iOS.

It explores a different approach to the iOS Home Screen — combining a modern interface, customizable application icons, widgets and interactive physics.

Powered by the idea of making the desktop feel alive, GravityContainer introduces a unique gravity-based interaction experience where icons become more than static elements.

Features

* Interactive Gravity — physics-inspired animations and dynamic icon interactions.
* Modern Interface — an aesthetic inspired by the latest iOS design language.
* Icon Customization — personalized icons and tinted appearances.
* App Integration — application launching through LiveContainer.
* Widgets — an experimental widget experience.
* Personalization — a desktop designed around the user’s preferences.

Built With

Swift · SwiftUI · UIKit

Vision

A Home Screen that feels alive.

An interface that moves, reacts and adapts — bringing a new dimension to the familiar iOS experience.
